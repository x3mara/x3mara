## 🚀 Featured projects

### [OrderMatchingEngine](https://github.com/x3mara/OrderMatchingEngine) `C++20` `CMake`
A multi-threaded order matching engine, the core of a financial exchange. It matches buy/sell orders against a live order book with price-time priority.
- Partial fills, O(1) order cancellation, and concurrent order submission through a mutex-guarded queue
- Benchmarked at roughly **45 to 48K orders/sec** end to end, with analysis showing the single matching thread is the bottleneck
